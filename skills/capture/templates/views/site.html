색인 문제

이 화면이 답하는 건 구글이 이 URL 을 색인했는가 하나입니다 — 구글 URL 검사 API 의 응답 그대로이고, 우리가 크롤해서 추정한 값이 아닙니다. 대신 페이지 속도·깨진 링크·중복 메타는 seo-miner 가 재지 않습니다. 검사 대상은 노출 상위 페이지부터입니다(하루 할당 2,000회).

페이지 축

어느 페이지가 죽고 있나

이 표만 페이지로 셉니다 — 나머지 화면은 전부 검색어 단위입니다. 검색어 하나의 순위는 표본 때문에도 흔들리지만, 그 검색어 수십 개를 담은 페이지는 잘 안 흔들립니다. 그래서 페이지가 내려가면 진짜 내려가는 것입니다. 새로 캐는 것은 없습니다 — 이미 읽어 둔 실적을 페이지로 다시 합쳤을 뿐입니다.

크롤 × 실적

아무도 안 오는 페이지

크롤이 200 으로 정상 응답한 페이지인데 검색 노출이 한 번도 없는 것들입니다. 페이지는 멀쩡한데 검색에 없다면 남는 원인은 셋입니다 — 색인이 안 됐거나(위 색인 표에서 같은 URL 을 찾아보세요), 아무도 안 찾는 주제이거나, 들어오는 링크가 없거나. 맨 위(얕고 링크 많은 페이지)부터 봅니다: 사이트가 이미 밀어 주는데도 안 온다면 링크 문제가 아니라 색인이나 수요 쪽입니다.

크롤 × 실적

내부링크가 굶은 페이지

노출은 상위인데 사이트 안에서 아무도 안 가리키는 페이지입니다. 성과는 이미 증명됐는데 사이트가 안 밀어 주는 상태라, 이 화면에서 가장 싼 자리입니다 — 관련 글 본문에 링크 한 줄이면 끝나고, 글을 새로 쓸 필요가 없습니다. 앵커에는 그 페이지가 걸린 검색어를 그대로 씁니다.
