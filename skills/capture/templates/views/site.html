URL 검사

색인 상태

구글 응답을 그대로 쓴다는 뜻

구글 URL 검사 API 의 응답 그대로입니다. 크롤해서 추정한 값이 아닙니다. 페이지 속도·깨진 링크·중복 메타는 여기 안 나옵니다. 검사는 노출 상위 페이지부터 하고, 하루 할당은 2,000회입니다.

전수 크롤

사이트 크롤

여러 쪽에 걸친 문제

사이트를 따라 돌며 링크와 페이지 상태를 전수로 본 결과입니다. 깨진 내부 링크·리다이렉트 사슬·고아 페이지는 한 장만 봐서는 안 나옵니다. 내 사이트만 두드리므로 비용이 없고, 고친 뒤 다시 크롤하면 해결된 것에 쌓입니다.

MOBILE vs DESKTOP

모바일 격차

고칠 곳이 글이 아닌 이유

같은 검색어를 기기별로 갈라 평균 순위를 맞대 본 것입니다. 격차가 크면 고칠 곳은 글이 아니라 모바일 화면입니다. GA4 가 연결돼 있으면 기기별 전환율을 옆에 나란히 놓아 페이지 자체를 의심할 자리인지까지 봅니다.

페이지 축

페이지별 실적

왜 페이지로 다시 셌나

이 표만 페이지로 셉니다. 나머지 표는 전부 검색어 단위입니다. 검색어 하나의 순위는 표본 때문에도 흔들리지만, 그 검색어 수십 개를 담은 페이지는 잘 안 흔들립니다. 그래서 페이지가 내려가면 진짜 내려가는 것입니다. 새로 캐는 것은 없고, 이미 수집한 실적을 페이지로 다시 합친 것입니다.

크롤 × 실적

노출 없는 페이지

남는 원인 셋

크롤이 200 으로 정상 응답 받은 페이지인데 검색 노출이 한 번도 없는 것들입니다. 남는 원인은 셋입니다. 색인이 안 됐거나(위 색인 표에서 같은 URL 을 찾습니다), 아무도 안 찾는 주제이거나, 들어오는 링크가 없거나입니다. 맨 위(얕고 링크 많은 페이지)부터 봅니다.

크롤 × 실적

내부 링크 부족

가장 싼 자리인 이유

노출은 상위인데 사이트 안에서 아무도 안 가리키는 페이지입니다. 성과는 이미 증명됐는데 사이트가 안 밀어 주는 상태라, 이 화면에서 가장 싼 자리입니다. 관련 글 본문에 링크 한 줄이면 끝나고 글을 새로 쓸 필요가 없습니다. 앵커에는 그 페이지가 걸린 검색어를 그대로 씁니다.

GA4 교차

전환 없는 페이지

이 표가 답하지 않는 것

서치콘솔은 클릭까지만 압니다. 이 표는 그 뒤(GA4 세션)까지 이어서, 클릭은 버는데 전환이 한 번도 안 잡힌 페이지를 봅니다. 표본이 되도록 클릭·세션 둘 다 최소치를 넘긴 페이지만 잡습니다. 왜 안 되는지는 이 표가 답하지 않습니다. 페이지를 직접 열어야 압니다.
