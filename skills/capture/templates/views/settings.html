1. 기본 부품

키워드 수집과 리포트에 쓰는 파이썬 부품 2개. 무료, 1분.

2. 첫 사이트

측정할 사이트를 등록합니다. 나중에 ~/.capture/projects/에서 고칠 수 있습니다. 웹(호스팅)에서 이미 쓰고 계셨다면 여기 등록하지 마세요 — 웹 [설정]의 "명령어로 연결하기" 한 줄을 채팅에 붙이면 그 사이트가 그대로 붙습니다.

3. 구글 서치콘솔 연결

내 OAuth 클라이언트 쓰기 — 경고 화면과 100명 상한이 없어집니다 (선택)

구글 클라우드 콘솔 → API 및 서비스 → 사용자 인증 정보 → [OAuth 클라이언트 ID 만들기] → 데스크톱 앱. 다 만들면 화면에 뜨는 두 문자열만 옮겨 적으시면 됩니다 — JSON 다운로드는 필요 없습니다. 저장하면 ~/.capture/gsc_oauth_client.json 이 되고, 동봉 클라이언트 대신 이게 쓰입니다. 클라이언트가 바뀌므로 로그인은 다시 한 번 하셔야 합니다. 시크릿은 저장 후 화면에 다시 표시되지 않습니다.

4. API 키

키가 하나도 없어도 기회 목록까지 갑니다. 측정을 막는 것은 위 3번 구글 로그인 하나뿐이고 그건 무료입니다. 아래 키는 새 기능을 사는 게 아니라 자동화를 사는 것입니다 — 없으면 그 단계만 건너뛰고 나머지는 그대로 돕니다. OpenRouter는 AI 노출 확인(ChatGPT·Perplexity·Gemini에 질문 수십 개를 자동 실행), DataForSEO는 순위·AI 요약·경쟁사 역키워드 측정. Serper는 DataForSEO 대체재(AI 요약 없음)라 보통은 필요 없습니다. 저장하면 ~/.capture/env에만 들어가고 화면에 다시 표시되지 않습니다. 비운 채 저장하면 지워집니다.

6. 웹에서 이어 하기 선택

같은 사이트를 웹에서 알아서 계속 재게 하고 싶을 때 씁니다. 아래 링크를 열고 구글 로그인만 하면, 여기 적어 둔 설정 그대로(도메인·종류·씨앗 키워드·브랜드 표기·경쟁사) 등록됩니다 — API 키는 서버가 대므로 다시 넣지 않습니다. 측정한 자료는 넘어가지 않습니다 — 웹이 자기 계정에서 처음부터 다시 잽니다. 여기서 쓰던 것은 그대로 남습니다.
