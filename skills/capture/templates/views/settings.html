2단계

사이트 등록

이 칸에 적은 값이 그 사이트 수집의 기준이 됩니다.i

웹에서 쓰던 사이트라면 여기 등록하지 않습니다

웹 [설정]의 명령어로 연결하기 한 줄을 채팅에 붙이면 그 사이트가 그대로 붙습니다. 여기 적은 값은 나중에 ~/.capture/projects/ 에서 고칠 수 있습니다.

명령에서 이 사이트를 가리킬 짧은 영문입니다.
기회를 뽑는 기준이 종류마다 다릅니다.
순위 확인과 크롤이 이 주소를 봅니다.
어느 언어·나라의 검색 결과에서 잴지 정합니다. 자동완성·AI 질문도 이 언어로 갑니다.
실적을 읽어 올 자리입니다. 비우면 sc-domain:도메인 을 씁니다.
AI 답변에서 우리 이름을 알아보는 데 씁니다. 쉼표로 여러 개.
여기서 자동완성으로 후보를 넓힙니다. 3~10개, 쉼표나 줄바꿈으로. 경쟁사 검색어와 백링크를 견줄 상대입니다. 선택이고 쉼표로 여러 개. 남의 브랜드 검색을 걸러냅니다. 쉼표로 여러 개.

3단계

서치콘솔 연결

클릭과 노출을 읽어 오는 구글 연결입니다.

내 OAuth 클라이언트 쓰기 — 경고 화면과 100명 상한이 없어집니다 (선택)

구글 클라우드 콘솔 → API 및 서비스 → 사용자 인증 정보 → [OAuth 클라이언트 ID 만들기] → 데스크톱 앱. 다 만들면 화면에 뜨는 두 문자열만 옮겨 적으면 됩니다. JSON 다운로드는 필요 없습니다. 저장하면 ~/.capture/gsc_oauth_client.json 이 되고, 동봉 클라이언트 대신 이게 쓰입니다. 클라이언트가 바뀌므로 로그인은 다시 한 번 해야 합니다. 시크릿은 저장 후 화면에 다시 표시되지 않습니다.

4단계

API 키

키가 없어도 기회 목록까지는 그대로 갑니다.

키가 하는 일과 저장되는 자리

측정을 막는 것은 위 3단계 구글 연결 하나뿐이고 그건 무료입니다. 아래 키는 새 기능이 아니라 자동화를 삽니다. 없으면 그 단계만 건너뛰고 나머지는 그대로 돕니다. 저장하면 ~/.capture/env 에만 들어가고 화면에 다시 표시되지 않습니다. 비운 채 저장하면 지워집니다.

ChatGPT·Perplexity·Gemini에 질문 수십 개를 자동으로 던집니다. 발급은 openrouter.ai/keys.
순위·AI 요약·경쟁사 검색어를 잽니다. 발급은 dataforseo.com.
계정 비밀번호가 아닙니다. API Settings 에서 확인합니다.
DataForSEO 대체재입니다. AI 요약을 못 재서 보통은 필요 없습니다. 발급은 serper.dev.
