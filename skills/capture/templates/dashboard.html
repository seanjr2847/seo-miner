seo·miner 채굴 로그

1. 기본 부품

키워드 수집과 리포트에 쓰는 파이썬 부품 2개. 무료, 1분.

2. 첫 사이트

측정할 사이트를 등록합니다. 나중에 ~/.capture/projects/에서 고칠 수 있습니다.

3. 구글 서치콘솔 연결

내 OAuth 클라이언트 쓰기 — 경고 화면과 100명 상한이 없어집니다 (선택)

구글 클라우드 콘솔 → API 및 서비스 → 사용자 인증 정보 → [OAuth 클라이언트 ID 만들기] → 데스크톱 앱. 다 만들면 화면에 뜨는 두 문자열만 옮겨 적으시면 됩니다 — JSON 다운로드는 필요 없습니다. 저장하면 ~/.capture/gsc_oauth_client.json 이 되고, 동봉 클라이언트 대신 이게 쓰입니다. 클라이언트가 바뀌므로 로그인은 다시 한 번 하셔야 합니다. 시크릿은 저장 후 화면에 다시 표시되지 않습니다.

4. API 키

자동화의 두 축은 채우는 걸 권합니다: OpenRouter는 AI 노출 확인을 질문 수십 개씩 자동 실행, DataForSEO는 순위·AI 오버뷰·경쟁사 역키워드 측정. Serper만 선택입니다 — DataForSEO 대신 쓰는 더 싸고 단순한 대체재(AI 오버뷰 없음)라 보통은 필요 없습니다. 저장하면 ~/.capture/env에만 들어가고 화면에 다시 표시되지 않습니다. 비운 채 저장하면 지워집니다.
