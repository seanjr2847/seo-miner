seo-miner

설정 — 채팅 없이 여기서 끝낼 수 있습니다

1. 기본 부품

키워드 수집·리포트에 쓰는 파이썬 부품 3개. 무료, 1분.

2. 첫 사이트

측정할 사이트를 등록합니다. 나중에 ~/.capture/projects/에서 고칠 수 있습니다.

3. 구글 서치콘솔 연결 (선택)

안 해도 CSV 내보내기로 실적을 읽을 수 있습니다. 연결하면 자동 수집 + 1,000행 제한이 풀립니다. 구글 클라우드 콘솔 클릭은 화면에서 대신 못 해 드립니다 — 채팅에 GSC 연동해줘 라고 하시면 제가 눌러 드리고, 열쇠 파일을 받은 뒤 아래 버튼을 누르시면 됩니다.

4. API 키 (선택)

자동화를 살 때만 필요합니다. 저장하면 ~/.capture/env에만 들어가고 화면에 다시 표시되지 않습니다. 비운 채 저장하면 지워집니다.
