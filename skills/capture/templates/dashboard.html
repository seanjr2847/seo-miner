3. 구글 서치콘솔 연결

안 해도 CSV 내보내기로 실적을 읽습니다. 연결하면 자동 수집 + 1,000행 제한이 풀립니다. 구글 클라우드 콘솔 클릭은 화면에서 대신 못 합니다 — 채팅에 GSC 연동해줘 라고 하시면 제가 눌러 드리고, 열쇠 파일을 받은 뒤 아래 버튼을 누르시면 됩니다.

4. API 키

자동화를 살 때만 필요합니다. 저장하면 ~/.capture/env에만 들어가고 화면에 다시 표시되지 않습니다. 비운 채 저장하면 지워집니다.
