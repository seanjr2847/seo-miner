seo·miner 채굴 로그

1. 기본 부품

키워드 수집과 리포트에 쓰는 파이썬 부품 2개. 무료, 1분.

2. 첫 사이트

측정할 사이트를 등록합니다. 나중에 ~/.capture/projects/에서 고칠 수 있습니다.

3. 구글 서치콘솔 연결

필수입니다 — 실적(클릭·노출)이 이 도구의 재료라, 연결 없이는 측정이 시작되지 않습니다. 무료·5분·계정당 1회. 기본은 내 구글 계정으로 로그인하는 방식(OAuth)입니다 — 로그인 한 번이면 내가 가진 속성이 전부 붙고, 속성마다 사용자를 추가하던 단계는 없어졌습니다. 구글 클라우드 콘솔에서 인증 파일('OAuth 클라이언트 ID' · 데스크톱 앱)을 내려받는 것은 여전히 필요합니다. 채팅에 GSC 연동해줘 라고 하시면 제가 콘솔 클릭을 대신하고 다운로드 버튼만 직접 눌러 주시면 됩니다. 받은 뒤 아래 버튼을 누르면 부품 설치까지 자동으로 이어집니다 (즉석 조회 MCP도 같은 인증을 씁니다 — 별도 설치 없이 다음 세션부터 붙습니다). 처음 조회할 때 브라우저 로그인 창이 한 번 열립니다. 사람 없이 도는 자동 수집이 필요하면 서비스 계정 키도 그대로 쓸 수 있습니다 — 같은 버튼으로 가져옵니다.

4. API 키

자동화의 두 축은 채우는 걸 권합니다: OpenRouter는 AI 노출 확인을 질문 수십 개씩 자동 실행, DataForSEO는 순위·AI 오버뷰·경쟁사 역키워드 측정. Serper만 선택입니다 — DataForSEO 대신 쓰는 더 싸고 단순한 대체재(AI 오버뷰 없음)라 보통은 필요 없습니다. 저장하면 ~/.capture/env에만 들어가고 화면에 다시 표시되지 않습니다. 비운 채 저장하면 지워집니다.
