이 사이트 설정

측정 주기와 연결

얼마나 자주 다시 잴지, 결과를 어디로 보낼지 정합니다. 고르면 그 자리에서 저장되고 다음 실행부터 적용됩니다.

자동 수집 주기

꺼도 [전체 분석 실행]과 첫 측정은 그대로 됩니다. 멈추는 것은 자동 재측정뿐입니다.

저장소 연결

개선 기회를 콘텐츠 초안으로 만들어 보낼 곳입니다. 초안은 사이트에 바로 반영되지 않고 검토용 변경안(PR)으로 올라갑니다. 읽어 보고 반영할지는 직접 정하시면 됩니다. 연결하지 않아도 나머지 측정은 그대로 됩니다.

GA4 연결

클릭 다음에 일어난 일(세션·매출·이탈률)을 랜딩페이지 축으로 봅니다. 연결하지 않아도 검색 실적 측정은 그대로 됩니다.
