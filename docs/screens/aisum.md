# [AI 요약] — 구글 검색 맨 위의 AI 요약에 우리 링크가 실리는지 보는 화면

구글 검색 결과 맨 위에 뜨는 AI 요약(AI Overview)이 검색어마다 떴는지, 떴다면 거기 **내 페이지가
출처로 실렸는지**를 봅니다. 이 화면이 답하는 질문은 하나입니다 — **"요약이 맨 위를 차지한 검색어에서
우리 링크는 실렸나, 빠졌다면 누가 그 자리를 가져갔나."** 요약이 떴는데 내 링크만 빠진 검색어는
순위가 그대로여도 클릭이 줄어듭니다.

챗봇(ChatGPT·Perplexity·Gemini) 답변에 우리 링크가 붙는지는 [AI 인용](aicite.md) 화면이 봅니다.
재료가 다릅니다: 이 화면의 재료는 추적 검색어를 구글에 조회한 결과(순위 확인 단계가 같이 걷어
옴)라서 챗봇 인용 확인이 없어도 섭니다. 두 화면은 메뉴의 같은 [AI 노출] 묶음에 나란히 서고, [이 묶음
다시 재기]는 `ai`·`rank` 두 단계를 같이 돌립니다 — 정본은 `run_all.GROUPS` 입니다.

화면 머리 아래에 **[할 것]·[전체]** 두 탭이 있습니다. **[할 것]**(열린 기회가 있으면 처음 열리는 탭, 건수
배지가 붙습니다)는 이 화면 몫으로 정해진 종류의 열린 기회 — 요약이 떴는데 링크가 빠진 검색어 — 를 한자리에서
처리하는 큐입니다. 줄·보드, 상태 거르개, 오른쪽 서랍, 상태 바꾸기, 요청문이 개요의 큐와 같은 부품이고,
종류↔화면의 정본은 `scoring.KINDS` 의 `see` 입니다. **[전체]**는 지금까지 이 화면이 보여 주던 비율·
대신 실린 곳·빠진 검색어 표·실린 검색어입니다. 열린 기회가 하나도 없으면 [전체]가 먼저 열리고, 한 번 고른
탭은 이 브라우저 탭이 기억합니다. [AI 요약에 빠진 검색어] 표는 큐와 같은 기회를 같은 서랍으로 열어 보이는
**근거 표**로 남습니다(순위·대신 인용된 곳을 한눈에 견주는 용도). 인쇄에는 두 탭의 내용이 다 나갑니다.

## 여기서 할 수 있는 것

| 할 일 | 어떻게 | 무엇이 바뀌나 |
| --- | --- | --- |
| 순위 다시 확인 | 화면 제목 옆 칩, 또는 띠의 [순위 다시 확인]. 로컬은 `/capture rank {사이트}` 명령 칩을 복사해 채팅에 붙여 넣고, 호스팅은 버튼이 바로 서버에서 돌립니다 | 추적 검색어마다 구글 결과를 다시 조회해 요약이 떴는지·내 링크가 실렸는지가 새로 채워집니다. 유료 단계입니다 |
| 빠진 검색어 보기 | 띠의 [빠진 검색어 보기] | [할 것] 탭으로 옮겨 큐의 맨 위 줄을 엽니다 |
| 할 일 열기 | 빠진 검색어 줄을 누릅니다 | 오른쪽 서랍에 그 검색어의 순위·요약이 대신 인용한 곳과, 기회가 있으면 기회 카드(요청문 포함), 없으면 순위 구간에 맞는 서버 처방이 열립니다 |
| 실린 검색어 확인 | [AI 요약에 실린 검색어]의 [펼쳐 보기] | 요약에 내 링크가 실린 검색어를 순위 순으로 봅니다 — 순위가 떨어지면 먼저 빠질 자리입니다 |

## 여기서 얻는 것

- **띠(한 줄 결론)**: `AI 요약이 뜬 N개 중 M개에서 우리 링크가 빠졌습니다.` 상태는 다섯입니다 — 순위를
  아직 안 쟀다 / 제공자가 요약을 안 준다 / 요약이 뜬 검색어가 없다 / 빠진 검색어가 있다 / 전부 실렸다.
- **[요약에 실린 비율]**: 요약이 뜬 검색어 중 내 페이지가 출처로 실린 비율과 막대, 확인한 검색어 수와
  빠진 곳 수. 개수는 화면용으로 30개에서 잘린 목록이 아니라 전체 조회 행에서 셉니다. 요약은 떴는데
  출처를 못 받은 검색어는 "안 실림"으로 세지 않고 "실렸는지 모른다"고 따로 적습니다.
- **[우리 대신 요약에 실린 곳]**: 우리가 빠진 검색어에서 요약이 출처로 실은 도메인을, 몇 개 검색어에
  실렸는지로 센 상위 8곳.
- **[AI 요약에 빠진 검색어]**: 요약은 떴는데 내 링크가 없는 검색어 표 — `검색어` `순위(직접 확인)`
  `대신 인용된 곳` `점수`. 목록은 서버가 고른 한 벌(`aio_gap`) 그대로이고 화면이 다시 판정하지
  않습니다. 순위는 같은 조회에서 우리 페이지가 있던 자리라 구글 실적의 평균 순위와 다른 숫자입니다.

## 언제 쓰나

- **"순위는 그대로인데 클릭이 줄었다."** 띠의 [빠진 검색어 보기] → 그 검색어에 AI 요약이 맨 위를
  차지했고 내 링크가 없는지 확인합니다. 있으면 줄을 열어 할 일(질문형 H2 + 직답, 출처 근거 등)을 읽습니다.
- **"요약이 대신 누구를 인용했나."** [우리 대신 요약에 실린 곳]에서 반복해 나오는 도메인이 그
  주제의 요약이 믿는 출처입니다.
- **"고친 뒤 실렸나."** 고친 페이지의 검색어가 다음 순위 확인 뒤 [AI 요약에 실린 검색어]로 옮겨 갔는지
  봅니다.

## 이 화면이 비어 보일 때

- **"구글 AI 요약은 아직 모릅니다"** — 순위 확인을 한 번도 안 돌렸습니다. [순위 다시 확인]을 누르면
  검색어마다 요약이 떴는지가 여기 섭니다.
- **"이번 순위 조회는 AI 요약을 재지 않았습니다"** — 지금 쓰는 순위 제공자(예: Serper)가 이 값을 주지
  않거나, 요약을 재기 전의 옛 조회입니다. AI 요약을 주는 제공자(DataForSEO)로 조회하면 채워집니다.
- **"AI 요약에 자리를 뺏긴 검색어가 없습니다"** — 확인한 검색어 어디에도 요약이 뜨지 않았습니다.
  순위가 바뀌면 달라질 수 있어 주기적으로 다시 봅니다.
- **"요약이 뜬 검색어에 전부 내 링크가 실렸습니다"** — 문제 없음. 순위가 떨어지면 요약에서도 빠지기
  쉽습니다.
