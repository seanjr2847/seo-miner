# 화면별 문서

대시보드(`/capture dash {사이트}`)의 화면마다 한 장씩. 각 장은 같은 꼴입니다 —
**한 줄 설명 · 여기서 할 수 있는 것 · 여기서 얻는 것 · 유즈케이스와 그림 · 비어 보일 때**.

전체 흐름과 명령 목록은 [리포 README](../../README.md#시작하기)에 있습니다. 여기는
"이 화면 앞에 앉았을 때 무엇을 할 수 있나"에 답하는 자리입니다.

## 측정 — 보고 고르는 곳

| 화면 | 무엇을 하는 곳인가 |
|---|---|
| [심사](triage.md) | 측정이 물어온 검색어를 기회로 세우기 전에 하나씩 가린다 |
| [개요](overview.md) | 지금 상태와 다음에 손댈 것을 한자리에서 본다 |
| [분석](analysis.md) | 클릭이 왜 늘고 줄었는지 원인별로 가른다 |
| [키워드](keywords.md) | 1페이지까지 남은 거리를 깊이로 그리고, 무엇부터 손댈지 고른다 |
| [순위 추적](rank.md) | 지금 몇 위인지, 그 위 AI 요약에 내 링크가 실렸는지 본다 |
| [AI 인용](ai.md) | 챗봇이 이 주제에서 누구를 인용하는지 본다 |
| [사이트 점검](site.md) | 검색엔진이 이 사이트에 닿는 길을 본다 |
| [백링크](backlinks.md) | 누가 우리를 링크하는지, 어디를 놓쳤는지 본다 |
| [경쟁 분석](competitors.md) | 경쟁사는 잡았는데 우리는 없거나 밀리는 검색어를 가려낸다 |

## 관리

| 화면 | 무엇을 하는 곳인가 |
|---|---|
| [기록](history.md) | 무엇이 언제 돌았고 무엇을 고쳤는지 본다 |
| [안내](guide.md) | 무엇을 해야 하는지와 지금 어디까지 왔는지를 모인 자료로 판정해 보여 준다 |
| [설정](settings.md) | 측정이 시작되기 전에 이 PC 에서 갖춰야 할 것을 채운다 |

## 화면이 아닌 것

| | |
|---|---|
| [기회 카드](opportunity-card.md) | 여덟 화면에 똑같이 뜨는 한 벌짜리 부품 — 접으면 "무엇부터 왜", 펼치면 "어디를 어떻게", 그리고 AI 에게 그대로 넘길 요청문 |

기회 카드를 화면마다 설명하지 않고 여기 한 장으로 둔 이유는, 그것이 여덟 화면에서
같은 부품이기 때문입니다. 화면마다 적으면 여덟 벌이 되고 버튼이 바뀔 때 한쪽만 낡습니다.

---

문서의 사실은 전부 코드에서 확인한 것입니다. 각 장 맨 끝에 근거(파일·줄)가 HTML
주석으로 남아 있습니다 — 화면이 바뀌면 그 자리부터 다시 보면 됩니다.
