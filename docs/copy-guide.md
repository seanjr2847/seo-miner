# seo-miner 카피 정본

이 문서가 화면 문구의 정본이다. 화면 파일(`skills/capture/templates/**`,
`server/assets/dash.html`, `server/landing.html`, `server/app.html`)을 고치는
사람은 여기 있는 말만 쓴다. 여기 없는 말을 새로 만들었으면 이 문서에 먼저 적고
고친다 — 그래야 다음 사람이 같은 것을 또 다른 이름으로 부르지 않는다.

## 1. 보이스 3원칙

**① 측정한 것만 말한다.** 이 제품이 파는 것은 추정이 아니라 구글이 기록한 값이다
(랜딩의 `MEASURED, NOT ESTIMATED` 가 그 약속이다). 그래서 화면도 재지 않은 것은
재지 않았다고 말한다. "데이터가 부족합니다" 가 아니라 "실적을 아직 수집하지
않았습니다" 다. 무엇이 없는지를 이름으로 말한다.

**② 다음 걸음으로 끝낸다.** 모든 상태 문장은 사용자가 지금 누를 것 하나로
닫힌다. 설명만 하고 끝나는 문장은 화면에 남기지 않는다. 오류도 같다 — "실패했습니다"
로 끝나는 문장은 이 리포에 없어야 한다.

**③ 짧게.** 한 문장 하나의 뜻. 부제는 한 문장. 빈 상태는 두 문장. 세 문장째부터는
`.hint[data-tip]` 툴팁이나 `<details>` 로 접는다. 지금 화면에 5문장짜리 부제가
여러 개 있는데(아래 나쁜 예), 그건 사용자가 안 읽는다.

## 2. 문체

| 자리 | 문체 | 길이 |
|---|---|---|
| 본문·부제·빈 상태 | 합니다체 | 부제 1문장 ≤ 45자 |
| 버튼 | 동사로 끝나는 **명사구** | ≤ 8자 (재실행 라벨은 ≤ 10자) |
| 제목(h1/h2) | 명사구 | ≤ 12자 |
| 빈 상태 제목 | 서술 한 마디 | ≤ 14자 |
| 마이크로 라벨(눈금·열 이름·배지) | 명사 | ≤ 6자 |
| 토스트 | 완료형 한 마디 | ≤ 14자 |

- **존댓말 명령 금지.** "누르세요" "확인하십시오" "새로고침하십시오" 는 쓰지 않는다.
  대신 무엇이 일어나는지를 적는다: "누르면 목록이 채워집니다."
- **버튼은 `-하기` 로 끝내지 않는다.** "설치하기" → "설치", "연결하기" → "연결".
  예외: 목적어가 있어 명사구가 자연스러운 것("링크 만들기", "질문 만들기").
- **하십시오체 금지.** 이 리포는 합니다체 한 벌이다. `server/app.html:558` 의
  "다시 골라 주십시오" 같은 잔재는 발견 즉시 고친다.
- **느낌표 금지.** 이모지 금지.
- **한글에 `letter-spacing`·`uppercase`·`--mono` 금지.** 라틴 문자열에만 `.lat` 을
  손으로 붙인다 (`CLAUDE.md` 의 「자간·등폭은 한글에 걸지 않는다」).

### 단계 이름은 여기 적지 않는다

단계(수집·분석의 실행 단위) 이름·설명·재실행 버튼 라벨의 정본은
`skills/capture/scripts/stage.py` 의 `STAGE_LABELS` 다. 화면은 조립이 실어 보낸
`window.__STAGES__` 를 읽는다. **화면 파일에 단계 이름을 글자로 옮겨 적지 않는다** —
`test_seams.py` 의 3번 항목이 그 사본을 잡는다. 버튼 라벨이 필요하면
`window.act(stage, label, primary)` 에 넘기고, 라벨을 비우면 `STAGE_LABELS` 의
`run` 이 들어온다.

### 기회 종류 이름도 여기 적지 않는다

`skills/capture/scripts/scoring.py` 의 `_KIND_SPECS` 의 `label=` 과 `SD_LABEL` 이
정본이고, 서버가 `kind_labels` 로 실어 보낸다. `striking_distance` 만 배지에
**밴드별 이름**(「1페이지 상단 가능」/「1페이지 진입 가능」)이 뜨고 필터 칩에는
**통칭**(「밀면 오를 검색어」)이 뜬다 — 이건 의도된 두 층이지 오류가 아니다.
다만 지금 화면은 그 둘이 같은 것임을 안 알려 준다. [개요] 담당은 칩에 밴드를
아는 경우 밴드 이름을 쓰거나, 칩 툴팁에 통칭을 붙인다.

## 4. 한 화면 한 벌 — `W()` 와 `data-web` 을 쓰는 법

이 리포에서 가장 크게 어긋난 자리다. 지금 `W(local, web)` 짝 **86개**와
`data-web` 속성 **35개**가 있는데, 그 대부분이 **같은 것을 다른 낱말로 부르는**
데 쓰이고 있다. 그래서 같은 제품이 두 개의 용어집을 갖게 됐다.

```
views/overview.html:331   W("클릭", "총 클릭수")
views/overview.html:333   W("노출", "총 노출수")
views/keywords.html:546   W("구글 실적을 아직 안 읽었습니다", "검색 실적을 아직 수집하지 않았습니다")
views/site.html:528       W("검사한 URL이 전부 색인돼 있습니다.", "검사한 URL 이 모두 색인 생성됐습니다.")
views/site.html            data-web="색인 생성 상태"     (원문: 색인 상태)
views/history.html         data-web="권장 조치"          (원문: 다음 행동)
dashboard.html:1752       W("지금 할 것", "권장 조치")
```

**규칙: `W()` 와 `data-web` 은 두 배포가 실제로 할 수 있는 일이 다를 때만 쓴다.**

| 써도 되는 것 | 쓰면 안 되는 것 |
|---|---|
| 로컬은 명령 칩(`/capture gsc`), 호스팅은 버튼 | 같은 뜻을 다른 낱말로 (「클릭」/「총 클릭수」) |
| 로컬은 "키를 설정에 넣으세요", 호스팅은 "키는 서버가 댑니다" | 같은 제목을 길게/짧게 (「다음 행동」/「권장 조치」) |
| 로컬만 있는 것을 가리킬 때(`~/.capture/env`, 채팅) | 같은 동사를 바꿔 부르기 (「읽었습니다」/「수집했습니다」) |
| 호스팅에만 있는 화면·설정을 가리킬 때 | 딱딱함의 정도만 다른 두 벌 (「그 줄 열기」/「그 행 열기」) |

갈릴 이유가 없는 짝은 **한쪽을 지우고 한 벌로 만든다.** 어느 쪽을 남기는지는
용어표가 정한다. 위 예시의 정답:

- `W("클릭", "총 클릭수")` → `클릭`
- `W("노출", "총 노출수")` → `노출`
- `W("구글 실적을 아직 안 읽었습니다", …)` → `실적을 아직 수집하지 않았습니다`
- `W("검사한 URL이 전부 색인돼 있습니다.", …)` → `검사한 URL 이 전부 색인됐습니다.`
- `data-web="색인 생성 상태"` → 삭제, 원문을 `색인 상태` 로
- `data-web="권장 조치"`, `W("지금 할 것", "권장 조치")` → `지금 할 것` 한 벌
- `W("그 줄 열기", "그 행 열기")` → `그 줄 열기`

## 5. 문장 공식

### 페이지 부제 (`.vh .sub1`)
> **[이 화면이 답하는 질문] 한 문장.** ≤ 45자, 마침표 하나.

설명 산문은 부제가 아니다. 두 문장째부터는 섹션 부제(`.sh .sub`)나 툴팁으로 내린다.

```
✗ 여기가 답하는 건 구글이 이 URL 을 색인했는가 하나입니다. 구글 URL 검사 API 의
  응답 그대로이고, 크롤해서 추정한 값이 아닙니다. 페이지 속도·깨진 링크·중복
  메타는 이 표에 안 나옵니다. 검사는 노출 상위 페이지부터 하고, 하루 할당은
  2,000회입니다.                                        (views/site.html:114)
✓ 구글이 이 주소들을 색인했는지 확인합니다.
  ⓘ 툴팁: 구글 URL 검사 API 응답 그대로입니다. 속도·깨진 링크·중복 메타는 여기
     안 나옵니다. 노출 상위부터 검사하고 하루 2,000회까지 됩니다.
```

### 다음 행동 띠 (`.next`)
> **[상태 한 마디]. [무엇을 하면 무엇이 됩니다].** + 버튼 1개(+보조 1개)

상태는 지금 사실, 뒷문장은 버튼을 누른 뒤의 결과. 버튼 이름을 문장 안에서
반복하지 않는다.

```
✗ 점수가 가장 높은 개선 기회는 1페이지 상단 가능입니다. 대상 페이지는
  beta-site 검색어.                                  (views/overview.html:306)
✓ 가장 큰 기회는 beta-site 검색어입니다. 1페이지 상단까지 2.4칸 남았습니다.
                                                     [기회 열기]
```

### 빈 상태 (`.empty`)
> **`<b>` 제목 ≤14자** — 무엇이 없나
> **`<p>` 한 문장** — 채우면 무엇이 되나
> **`.acts` 버튼 1개** — 채우는 법

「왜 비었는지」를 사용자 탓으로 쓰지 않는다. 재료가 없다는 사실만 적는다.

```
✓ <b>실적을 아직 수집하지 않았습니다</b>
  <p>수집하면 1페이지 문턱에 걸린 검색어부터 채워집니다.</p>
  [실적 수집]
```

버튼이 이 화면에서 못 하는 일이면(다른 화면으로 가야 하면) `window.go()` 로
그 화면 이름을 단 보조 버튼을 쓴다: `[경쟁 분석 열기]`.

### 오류 상태 (`.empty.err`)
> **`<b>` 무엇이 실패했나** + **`<p>` 왜(알면) · 지금 할 것** + **[다시 시도]**

"서버가 응답하지 않았습니다" 로 **끝내지 않는다**. 원인 뒤에 반드시 복구 행동이
온다. `server/assets/dash.html:479` 의 주석이 이미 이 규칙을 적어 뒀다 — 지키면 된다.

```
✗ 마지막 수집에서 실패한 단계가 있습니다: 402                (dash.html:435)
✓ <b>지난 수집에서 순위 확인이 실패했습니다</b>
  <p>순위 제공자 잔액이 0입니다. 충전한 뒤 다시 확인하면 이어서 채워집니다.</p>
  [순위 다시 확인]
```

### 진행 상태
> `.badge.run` + `.progress` + **「[단계 이름] 도는 중」** 한 마디.

남은 시간을 지어내지 않는다. 모르면 무엇이 도는지만 적는다.

### 확인 대화 (`confirm`)
> **[무엇이 사라지나] + [되돌릴 수 있나].** 두 문장, 두 번째는 대안.

```
✓ 이 질문과 지금까지의 확인 기록을 지웁니다.
  기록을 남기려면 지우지 말고 체크만 꺼 주세요.        (dash.html:1328 — 좋은 예)
```

### 닥터 배너 (`doctor.diagnose()` 의 `must` 항목)

이 배너는 화면이 아니라 `doctor.py` 가 문장을 정한다. 그래서 형식도 여기서 정한다.
한 항목이 세 자리를 갖는다.

| 자리 | 무엇 | 규칙 |
|---|---|---|
| `msg` | 결론 | **최대 두 문장.** 그것만 읽어도 뜻이 서야 한다. 되돌릴 수 없는 손실(자료가 사라진다)은 반드시 여기 |
| `detail` | 나머지 사정 | 화면이 `<details>` `[자세히]` 로 접는다. **없으면 `None`** — 빈 문자열을 주면 접을 것 없는 접이가 생긴다 |
| `go` | 누를 곳 | `{"label", "href"}` 아니면 `None`. 로컬은 `cmd` 가 행동이라 대개 `None`, 호스팅은 칠 곳이 없어 여기가 유일한 행동 |
| `cmd` | 복사할 명령 | 로컬 전용, 호스팅은 항상 `None`. **`detail` 안에 넣지 않는다** — 접힌 곳에 행동을 숨기지 않는다 |

**목적지는 서버가 준다.** 화면이 `id` 별 행동표를 따로 들면 그 표는 배포가 갈리는
순간 낡는다. 그리고 「어디로 보낼지」는 항목마다 다르다 — 호스팅에서 구글 재연결은
`/auth/login` 이고 사이트 고르기는 `/` 다. **설정 화면이 아니다**(호스팅 설정에는
구글 연결 항목이 아예 없어서, 그리로 보내면 막다른 길이 된다).

**누를 곳이 없으면 없다고 말한다.** 서버가 고칠 문제(`core_deps`·`brain_broken`·
`gsc_client`)는 사용자가 갈 곳이 없다. `go` 를 `None` 으로 두고 `msg` 가
「잠시 뒤 다시 시도해 주세요」로 왜 없는지 말한다. 여기에 목적지를 지어내면 아무것도
못 하는 화면으로 보내게 된다.

`doctor._selfcheck()` 가 이것들을 못 박는다: `msg` 마침표 2개 이하, `detail` 은
`None` 이거나 내용이 있는 문자열, `go` 는 `None` 이거나 `label`(≤10자)+`href`,
`go`·`cmd` 둘 다 없으면 `msg` 에 「잠시 뒤」가 있을 것, 호스팅 갈래의 `msg`·`detail`
둘 다에 명령·경로·「채팅」이 없을 것. 서버 쪽 항목은 이 머신에서 안 만들어지므로
**소스를 `ast` 로 읽어** 검사한다(`_must_entries()`). 안 그러면 통과하는 검사가
아니라 아무것도 안 보는 검사가 된다. CLI(`render`)는 접을 곳이 없으므로 `detail` 을
한 칸 들여 찍는다.

```
✗ 저장된 로그인에 GA4 읽기 권한이 없어 GA4 수집이 막힙니다. 검색 실적 수집은
  그대로 됩니다. 저장된 로그인을 지우고 다시 로그인해야 새 권한까지 동의합니다.
  안 지우면 기존 로그인을 그대로 재사용해 동의 창이 안 뜹니다. Claude 에게
  부탁하시면 지우는 것부터 대신 합니다.                              (5문장)
✓ msg    저장된 로그인에 GA4 읽기 권한이 없습니다. 검색 실적 수집은 그대로 됩니다.
  detail 저장된 로그인을 지우고 다시 로그인해야 새 권한까지 동의합니다. 안 지우면
         기존 로그인을 그대로 재사용해 동의 창이 안 뜹니다. Claude 에게 부탁하시면
         지우는 것부터 대신 합니다.
```

### 토스트 (`toast(msg, kind)`)
> 완료형 한 마디, ≤14자, 마침표 없음.

`복사됨` · `수집을 시작했습니다` · `저장했습니다` · `보내지 못했습니다`

## 7. 금지 목록

1. **결제 벽 어투.** "업그레이드하면 볼 수 있습니다", "유료 플랜 전용",
   "OpenRouter 키가 필요합니다". 이 제품에 결제 벽은 없다 — 유료 키가 없으면 그
   단계만 건너뛰고 아하 모먼트(기회 목록)까지는 그대로 간다. 그래서 순서가 규칙이다.

   > **[없어도 되는 것] 먼저, [키를 넣으면 되는 것] 나중.**

   ```
   ✗ ChatGPT·Perplexity·Gemini가 누구를 인용하는지 봅니다. OpenRouter 키가 필요합니다.
   ✓ ChatGPT·Perplexity·Gemini가 누구를 인용하는지 봅니다. 없어도 기회 목록까지는
     그대로 가고, OpenRouter 키를 넣으면 켜집니다.
   ```

   문장 앞머리의 정본은 `stage.NOT_BLOCKING` 한 줄이다. `doctor.py` 의 잠금
   사유(`CAPABILITIES.fix`)도 같은 말로 시작한다. `stage._selfcheck()` 가 유료 키를
   말하는 단계마다 이 말이 **있는지**와 **키 요구보다 앞에 오는지**를 대조한다.
   호스팅(`GAIN_WEB`)은 서버가 키를 대므로 요구 자체가 없고, 검사 대상도 아니다.
2. **사용자 탓.** "잘못 입력하셨습니다", "먼저 ~하셨어야 합니다", "설정을 안
   하셔서". 재료가 없다는 사실만 적는다.
3. **복구 행동 없는 오류.** "서버가 응답하지 않았습니다." 로 끝나는 문장.
4. **설명 산문 3문장 이상.** 부제·빈 상태 어디에도.
5. **상태를 버튼 모양으로.** `dash.html:719` 의 `"저장소 연결 필요"` 는 버튼
   자리에 있는 상태다. 상태는 `.badge`, 행동은 `.go` — 절대 섞지 않는다.
6. **한글 자간·등폭.** `letter-spacing`·`uppercase`·`--mono` 는 라틴에만, `.lat` 로.
7. **두 벌 용어.** 4장 참조. 갈릴 이유가 없는 `W()`·`data-web` 은 지운다.
8. **정본 복사.** 단계 이름, 기회 종류 이름, 화면 목록을 화면 파일에 글자로
   옮겨 적는 것. `test_seams.py` 가 잡는다.
9. **로컬 전용 문구가 호스팅으로 새는 것.** 「채팅에 붙여 넣으세요」, `/capture …`,
   `~/.capture/env`, 「Claude 에게 부탁하시면」. 지금 호스팅 [개요]에
   `/create profile <이름>` 과 `토큰 삭제하고 GSC 로그인해줘` 칩이 실제로 새고
   있다 (`cur/h-overview.png`) — 호스팅 담당이 잡는다.
10. **약어 남발.** SERP·AIO·CTR·GSC 는 산문에 쓰지 않는다. 표 열 이름과 `.lat`
    eyebrow 에서만.

### `dofollow` 를 왜 「순위 반영」으로 부르나

`dofollow`/`nofollow` 는 링크에 `rel="nofollow"` 가 붙었는지를 가리키는 업계
용어다. 이 제품의 독자는 그 낱말을 모르고, 알아야 할 것은 **그 링크가 순위에
넘어오느냐** 하나다. 그래서 뜻을 그대로 이름으로 쓴다.

`점수 전달` 도 후보였지만 버렸다 — 이 리포에서 「점수」는 이미 기회 점수(0~100)를
가리킨다. 같은 낱말이 두 뜻을 가지면 표에서 읽는 사람이 두 번 생각한다.

| 자리 | 지금 | 바꿀 말 |
|---|---|---|
| `views/backlinks.html:213` KPI | `dofollow 비율` | `순위 반영 비율` |
| `views/backlinks.html:242` 열 이름 | `dofollow` | `순위 반영` |
| `views/backlinks.html:342` 칸 값 | `dofollow` / `nofollow` | `반영` / `안 됨` |
| `views/backlinks.html:357`·`366` CSV 머리 | `dofollow` | `순위 반영` (화면 열 이름과 같게) |
| `views/backlinks.html:213` 눈금 | `nofollow 는 순위로 잘 안 넘어갑니다` | `업계 용어로 dofollow · nofollow 입니다.` 를 `.hint` 로 |

**DB 열 이름과 API 키(`dofollow`·`nofollow`)는 그대로 둔다.** 바꾸는 것은 사람이
읽는 자리뿐이다. `.lat` 도 쓰지 않는다 — 이제 라틴이 아니다.

### 빈 상태 기본 문장을 왜 안 갈랐나

`dashboard.html` 의 표 빈 상태 기본 문장은 `W()` 를 통째로 없애고 한 벌로 합쳤다.

```
"<b>아직 채울 자료가 없습니다</b><p>이 화면을 채우는 단계를 한 번 돌리면 표가 생깁니다.</p>"
```

이 기본 문장에는 **행동 요소가 아예 없다**. 부르는 쪽이 `empty` 인자로 더 구체적인
말과 버튼을 주면 그쪽이 이긴다. 여기서 「명령을 치세요 / 버튼을 누르세요」를 갈라
봐야 같은 말을 두 낱말로 부르는 것이고, 무엇을 누르는지는 화면 머리의 칩·버튼이
이미 말한다. **갈라야 할 것은 낱말이 아니라 행동이고, 행동은 `empty` 가 갖는다.**
이 판단이 4장 규칙의 실제 적용 예다.

### 그대로 두는 좋은 예

바꾸지 말 것. 이 리포가 이미 잘 쓰고 있는 문장이다.

- `server/landing.html:386` `안 하는 것부터 말씀드립니다.` — 신뢰를 사는 정직한 소제목.
- `server/landing.html:429` `내 사이트가 지금 몇 위인지, 1분이면 봅니다.` — 결과 + 비용.
- `dash.html:1328` `이 질문과 지금까지의 확인 기록을 지웁니다. 기록을 남기려면 지우지 말고 체크를 꺼 주세요.` — 파괴적 확인의 교본.
- `views/analysis.html:100` `잃은 쪽 맨 위부터 봅니다. 줄을 누르면 어느 페이지를 고칠지 나옵니다.` — 두 문장이 각각 한 가지 행동.
- `views/ai.html:881` `확인이 아직 1회뿐이라 추이가 없습니다.` — 없는 이유를 재료로 설명.

## 9. 화면 담당 체크리스트

커밋 전에 자기 화면에서 이것만 본다.

- [ ] 제목 옆 부제가 **한 문장**인가. 두 문장째는 ⓘ 툴팁이나 `<details>` 로 내렸나.
- [ ] 채운 버튼(`.go`)이 이 화면에 **정확히 하나**인가.
- [ ] 버튼 글자가 ≤8자(재실행 ≤10자)이고 `-하기` 로 안 끝나는가.
- [ ] `W()`·`data-web` 이 남아 있다면, **두 배포가 할 수 있는 일이 실제로 다른가**.
- [ ] 단계 이름·기회 종류 이름을 글자로 옮겨 적지 않았는가.
- [ ] 오류 문장이 **행동으로 끝나는가**.
- [ ] 빈 상태 제목이 ≤14자이고, 본문이 사용자를 탓하지 않는가.
- [ ] 용어표에 없는 낱말(쿼리·게재순위·임프레션·SERP)이 산문에 없는가.
- [ ] 한글에 `letter-spacing`·`uppercase`·`--mono` 가 안 걸렸는가.
- [ ] `python run_checks.py render` 가 통과하는가.
